Programming for Problem Solving using C++ 🚀💻

SYLLABUS 📚

Programme: B. Tech. L: 2 T: 0 P: 0
Semester: 1 Teaching Hours: 26 hours
Theory/Practical: Theory Credits: 2
Internal Marks: 40 Numerical/Design Problems: 60% 📊
External Marks: 60 ESE Duration: 3 hours 🕒
Total Marks: 100 Elective Status: Compulsory

🛠 Prerequisites: None

🎯 Course Outcomes

CO# What You’ll Achieve 🎓
1️⃣ Understand the working of computers and design algorithms for problem-solving. 🤔
2️⃣ Formulate algorithms for arithmetic and logical problems. 🧮
3️⃣ Test, execute, and debug programs. 🐞
4️⃣ Implement conditional branching, iteration, and recursion. 🔄
5️⃣ Solve problems using functions with a divide-and-conquer approach. ✂️➡️📈
6️⃣ Use arrays and structures to create programs. 📋

📑 Detailed Contents

Part-A: Foundations

Unit-1: Introduction to Computers 🖥️

  • Components of Computer Systems:
    Input/Output Devices, Memory, Storage Devices.
  • Block Diagram of a Computer System.
  • Software Overview: System vs. Application Software, Types of Operating Systems, Compiler, Interpreter, Assembler, Linker, Loader.

Unit-2: Basics of Programming 📝

  • Algorithm Basics: Steps for solving logical/numerical problems.
  • Algorithm Representation: Flowchart 📈, Pseudocode, and examples.
  • C++ Program Structure: From writing to execution, including tokens, data types, and error handling.

Unit-3: Arithmetic Expressions and Precedence ➗

  • main() Function and conventions.
  • Operators Overview:
    • Assignment =
    • Numeric (+, -, *, /, %)
    • Prefix/Postfix (++/–)
    • Logical, Bitwise, Relational
    • Type conversion and operator precedence.
  • Input/Output Streams Basics.

Unit-4: Control Structures 🔀

  • Conditional Statements:
    if, if-else, conditional operator ?:, switch, nested decisions.
  • Loops:
    for, while, do-while, nested loops.
  • Keywords: break, continue, goto, switch-case.

Part-B: Advanced Concepts

Unit-5: Functions 🛠️

  • Why Functions Matter?
  • Types of Functions: Built-in, User-defined.
  • Parameter Passing: Call by value & reference.
  • Concepts: Scope, Default Arguments, Function Overloading, Recursion.

Unit-6: Arrays 📊

  • Single & Multi-Dimensional Arrays.
  • Character Arrays and Strings.
  • String Operations: Declaration, initialization, comparison, and manipulation.

Unit-7: Structures and Unions 🏗️

  • Why Structures?
  • Operations: Passing/returning structures, nested structures, arrays of structures.
  • Unions vs. Structures.
